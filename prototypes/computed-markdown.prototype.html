Computed Markdown · logic prototype

The question. A hand‑written template holds marked regions. A tool renders each region from a data source, writes the result to CLAUDE.md at the canonical path, and records a sum in the closing marker. Does this model feel right once you push it through the awkward cases: a file appears, someone edits the output by hand, a renderer fails, the tool's own write comes back as a filesystem event, a shell region that is never the same twice?

Prototype, throwaway. Everything is in memory. The logic lives in one pure module at the bottom of this file, shaped to lift into the Rust prototype's modules: parse, render, write, check, watch. No symlinks, per the decision in docs/research.
